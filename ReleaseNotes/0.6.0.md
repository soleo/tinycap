Name your recordings and screenshots before you save them.

- **Name field:** the export panel and the screenshot editor have a file name field, filled in from your filename pattern. Click it and type to replace the whole name; the extension follows the format. Return exports.
- **Export As… and Save As… (⇧⌘S):** pick any name and folder for one file with the standard macOS save dialog.
- **No silent overwrites:** if the name is taken, choose Keep Both (adds " 2") or Replace. A failed or cancelled export leaves the old file alone.
- **Rename after export:** click the exported recording's name to rename the file.
- **New pattern tokens:** {type} (Recording or Screenshot), {app}, {window} and {n} (a counter), alongside {date}, {time} and {seconds}. Settings → General has a button for each token and shows example names as you type.
- Recordings are now named by when you started recording, not when you exported. Names made with the default pattern look the same as before.
