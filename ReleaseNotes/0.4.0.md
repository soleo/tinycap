Five new ways to mark up a screenshot.

- **Rectangles and ellipses:** outline a button, a field or an error. Hold Shift for a square or circle, and drag a corner to resize.
- **Highlighter:** a wide, see-through stroke that keeps the text underneath readable. Hold Shift to draw it straight across a line.
- **Pen:** draw freehand, smoothed as you go.
- **Numbered steps:** click to drop 1, 2, 3 for a walkthrough. Delete one and the rest renumber themselves.
- Each tool has a one-letter shortcut: R rectangle, O ellipse, H highlighter, D pen, N number. Hover over a tool to see its key.
- The toolbar now shows icons, leaving room for the color and size controls.
- **Homebrew:** install with `brew install --cask soleo/tap/tinycap`.
