- **Highlight clicks:** a yellow ring marks each click in screen and area recordings. Turn it on in Settings → Recording.
- **Countdown:** an optional 3-2-1 before recording starts. Press Esc to cancel.
- **Updates:** Tinycap checks for a new version once a day and reminds you quietly with a dot on the menu-bar icon. It never interrupts a recording. You can turn this off in Settings → General.
- **Report a Bug and Send Feedback** open a GitHub issue with your Tinycap and macOS versions filled in. Tinycap sends nothing itself.
- **About** in Settings shows the version, build date and commit, with links to the source and release notes.
- Fixed: Tinycap's own windows could appear in screen and area recordings.
