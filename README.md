# Tinycap landing page

Static site for https://soleo.github.io/tinycap/ — plain HTML and CSS, no build step, no scripts, no trackers.

Edit `index.html` and `styles.css`; icons in `assets/` are generated from `Resources/AppIcon-1024.png` on `main`. When a new version ships, update the download links, version, the "what's new" link, size and the `styles.css?v=` tag (search for `0.3.0` and `5.8 MB`).
