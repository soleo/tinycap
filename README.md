# Tinycap landing page

Static site for https://soleo.github.io/tinycap/ — plain HTML and CSS, no build step, no scripts, no trackers.

Edit `index.html` and `styles.css`; icons in `assets/` are generated from `Resources/AppIcon-1024.png` on `main`. When a new version ships, update the download links, version, the "what's new" link, size and the `styles.css?v=` tag (search for the old version, e.g. `0.4.0`, and the old size, e.g. `5.1 MB`; take the size from the DMG's byte count in decimal MB, as Finder shows it).
